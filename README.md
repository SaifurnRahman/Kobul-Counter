# 💍 কবুল কাউন্টার (Kobul Counter)

কবুল বলার পর থেকে প্রতিটা সেকেন্ডের হিসাব। বিবাহিতদের জন্য ট্র্যাকার, আর অবিবাহিতদের জন্য রোস্ট 🔥

## ফিচার
- **লাইভ কাউন্টার**: বছর, মাস, দিন, ঘণ্টা, মিনিট, সেকেন্ড (অ্যানিমেটেড)
- **শুক্রবার আর ঈদ**: কতগুলো শুক্রবার গেছে, আর ঈদুল ফিতর ও ঈদুল আযহা আলাদা করে (ব্রাউজারের Umm al-Qura হিজরি ক্যালেন্ডার দিয়ে, সার্ভার লাগে না)
- **পরিবার**: বিয়ের আগে ২ জন → এখন কতজন, প্রতিটা সন্তানের বয়স
- **এক লাইনে অনুভূতি**: "বিয়ে মানে…" দিয়ে শুরু
- **তিন ক্যালেন্ডারে বিয়ের তারিখ**: ইংরেজি, বাংলা (বঙ্গাব্দ), হিজরি
- **ফটো কার্ড**:
  - ৪টা টেমপ্লেট: বাঙালি বিয়ে, মিনিমাল, মজার, ইসলামিক
  - সাইজ: ১:১ পোস্ট আর ৯:১৬ স্টোরি
  - ছবির শেপ: গোল বা হার্ট
  - কার্ডে QR কোড আর বাংলা সংখ্যা থাকে
- **সিঙ্গেল মোড**: রোস্ট লাইন, একা কাটানো ঈদ আর শুক্রবারের হিসাব, "দোয়া চাই" বাটন, রোস্ট কার্ড
- **বিশেষ দিন**: বিবাহবার্ষিকী আর প্রতি ১০০ দিন পূর্ণ হলে কনফেটি 🎉
- **ভাষা আর থিম**: বাংলা/English টগল, ডার্ক মোড
- **ফ্রি ভিজিটর ও ডাউনলোড কাউন্টার**: [Abacus](https://abacus.jasoncameron.dev) দিয়ে, সাইনআপ লাগে না
- **প্রাইভেসি**: সব তথ্য শুধু ব্রাউজারের localStorage-এ থাকে, কোনো সার্ভারে যায় না

## টেক
React 19 + Vite, Tailwind CSS v4, Framer Motion, canvas-confetti, qrcode-generator, Hind Siliguri ফন্ট (লোকাল, `public/fonts`)

## চালানো
```bash
npm install
npm run dev
```

## Deploy (ফ্রি)
১. `src/config.js` খুলুন:
   - `COUNTER_NS`-এ নিজের একটা ইউনিক নাম দিন।
   - চাইলে `SITE_URL`-এ নিজের ডোমেইন দিন (খালি রাখলে যে সাইটে হোস্ট করা, সেই লিংকই QR কোডে যাবে)।
২. বিল্ড করুন:
```bash
npm run build
```
৩. তৈরি হওয়া `dist` ফোল্ডারটা [Netlify Drop](https://app.netlify.com/drop)-এ টেনে ছেড়ে দিন। অথবা Vercel বা GitHub Pages ব্যবহার করুন।

ভিজিট আর ডাউনলোড কাউন্টার সাইটের নিচে দেখা যায়। localhost-এ টেস্ট করার সময় এগুলো বাড়ে না।

## বিস্তারিত অ্যানালিটিক্স (GoatCounter, ফ্রি)
১. [goatcounter.com](https://www.goatcounter.com)-এ ফ্রি অ্যাকাউন্ট খুলুন আর একটা কোড বাছাই করুন (যেমন `kobul`)।
২. `src/config.js`-এ `GOATCOUNTER_CODE: 'kobul'` লিখুন, তারপর আবার build ও deploy করুন।
৩. ড্যাশবোর্ড খুলুন: `https://kobul.goatcounter.com`

ড্যাশবোর্ডে যা দেখবেন:
- ভিজিটর সংখ্যা, দেশ, মোবাইল বা কম্পিউটার, কোন সাইট থেকে এসেছে
- `mode/married`, `mode/single`: কতজন "হ্যাঁ" আর কতজন "না" চেপেছে
- `download/card-<টেমপ্লেট>-<সাইজ>`: কোন টেমপ্লেট আর সাইজের কার্ড কতবার ডাউনলোড হয়েছে (যেমন `download/card-trad-square`)
- `download/roast-<সাইজ>`: সিঙ্গেলদের রোস্ট কার্ড ডাউনলোড
- `share/...`: মোবাইল থেকে শেয়ার
- `dua`: কতজন দোয়া চেয়েছে

localhost-এ GoatCounter নিজে থেকেই কিছু গোনে না, তাই টেস্টিং হিসাবে আসবে না।

## ফোল্ডার
```
src/
  config.js            সাইট URL ও কাউন্টার সেটিং
  lib/dates.js         বয়স, শুক্রবার, ঈদ, বঙ্গাব্দ, হিজরি হিসাব
  lib/card.js          ফটো কার্ড (canvas) ড্রয়িং
  lib/i18n.js          বাংলা/English টেক্সট
  lib/counter.js       ভিজিট/ডাউনলোড কাউন্টার (Abacus)
  lib/analytics.js     GoatCounter অ্যানালিটিক্স
  components/          পেজ ও UI কম্পোনেন্ট
```
